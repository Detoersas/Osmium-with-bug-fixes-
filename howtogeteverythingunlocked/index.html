Guest network access

Connect to the WiFi network

Welcome. This page is the official guest guide for this network. Follow the steps below, then use the access code provided by the network owner.

1
Join the WiFi network

Open your device’s WiFi settings, select the guest network, and connect. If the network has no password, choose Connect.

2
Open the guest page

Return to this page after connecting. If it does not open automatically, use the address supplied by the network owner.

3
Enter the access code

Ask the network owner for the current code. Never share it publicly.
