DNS setup example

These are example Windows steps. Use only DNS values supplied by the owner of the network.

  1. Open Network & internet → Wi-Fi and select the connected network.
  2. Choose DNS server assignment → Edit, then select Manual.
  3. Enable IPv4, enter the owner-provided preferred and alternate DNS values, and select Save.
  4. Last step — example: reconnect to the guest Wi-Fi, open a new browser tab, and visit the network owner's approved landing page to confirm the connection.

Example only: DNS changes do not grant router authorization. Your router or WISP captive portal must approve guests separately.
