DNS setup example

Use these screenshots as a visual example only. Enter DNS values supplied by the network owner.

  1. Open Network & internet → Wi-Fi.
  2. Select DNS server assignment → Edit and choose Manual.
  3. Enable IPv4 and enter the provided values.
  4. Save the settings. This is the example final step.
